* Findings
:PROPERTIES:
:CUSTOM_ID: findings
:END:
- App will not use user CAs (requires patching).
- TPs seem very inconsistent, logic analyzer is needed to decode
  protocol.
- Using logic analyzer while plug is connected is risky. Desolder wifi
  board first and power with 3.3 V instead.
